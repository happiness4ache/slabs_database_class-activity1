# the Information System Analysis: WhatsApp

# the FIve Pillars
1) hardware- this app rely on several devices like Smartphones,Laptops,network equipment and company servers
2) software- the WhatsApp app(Android/IOS/desktop), the phone operating system(Android/IOS), the server side software and databases
3) data- we have phone numbers, messages, read statuses, contacts, profile photos and when you are sharing your location
4) people- can be Users, Group Admins, Support Team, and Developers and Also support staff
5) process- users type meassages to one another, the app encrypts it, the server routes it, another person or the recipient receives the message, the status are being updated and delivered then read
